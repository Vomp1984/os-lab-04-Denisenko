cmdline - информация о том какой процесс активен.
environ - переменная для передачи баз данных, такинов входа и тд. По этому информация в первом случае может быть получена любым пользователем а во втором случае нет.
Для передачи пароля программе подходит ручной ввод или файл конфигурации с правами 600(подходит для автоматизации).
